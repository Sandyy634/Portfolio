I'm Sandesh Kandel, a Cybersecurity & Ethical Hacking student based in Kathmandu, Nepal. I'm drawn to the offensive side of security — understanding how systems are broken so they can be built better.

My work spans keyloggers, RATs, web crawlers and recon tools — all built for educational and lab environments. Every project is a lesson in how attackers think, and how defenders must respond.

When I'm not coding, I'm studying CVEs, hunting bugs on CTF platforms, or reading security writeups at 2am. Security isn't what I do — it's how I see the world.
